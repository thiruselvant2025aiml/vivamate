# 🚀 VivaMate – AI Viva Practice Assistant

VivaMate is an AI-powered web application designed to help students practice technical viva examinations.

## 🌐 Live Demo

👉 **[Open VivaMate](https://vivamate-tnzj.onrender.com)**

## ✨ Features

- 🔐 Student Registration & Login
- 🎯 Subject and Topic Selection
- 🧠 AI-based Viva Questions
- 🎤 Voice-based Answer Input
- 🔊 Question Voice Playback
- 📊 Answer Evaluation
- 🔄 Adaptive Follow-up Questions
- 📈 Viva Performance Tracking
- 📚 Viva History
- 🌙 Premium Dark AI Interface

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Web Speech API
- OpenAI API integration
- Gunicorn
- Render

## 🎓 Project Purpose

VivaMate helps students improve their technical communication and viva preparation through interactive question-answer practice and automated feedback.
